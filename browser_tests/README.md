# Selenium browser tests

Run from the project root in PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r browser_tests/requirements.txt
.\.venv\Scripts\python.exe browser_tests/make_fixture.py
.\.venv\Scripts\python.exe -m pytest -c browser_tests/pytest.ini browser_tests --browser chrome --demo-delay 0.7 --junitxml outputs/selenium/results.xml
```

Tests run sequentially in six fresh, visible Chrome sessions (or `--browser edge`). No xdist is used. The dedicated Waitress child binds an OS-assigned loopback port, is checked over HTTP, and is terminated by its own process handle in teardown. Each session uses a fresh browser profile and a separate downloads directory. Explicit waits check page readiness, responses, rendered charts, sheet replacement, and completed PNG downloads. `--demo-delay` specifies seconds after major actions and final assertions; default 0.7. PNGs are signature-checked, verified and fully decoded with Pillow.

Evidence is retained under `outputs/selenium/<run timestamp>/<test name>/`: final or failure full-page screenshots, browser capabilities, assertion outcome and downloads. Server/application logs are isolated in the same run folder. Setup errors before a browser is available cannot produce a browser screenshot. JUnit XML also records setup and teardown errors.

## Independent expectations

The oracle is `docs/SRS_DataVisualisation_v0.3.md`, not application constants: section 4.7.3 supplies full E-01 and E-03 messages; FR-19 and FR-49 specify summary/statistics; FR-34 and US-05 specify first usable sheet and selector refresh; FR-24 specifies the built-in PNG button.

Reuse `outputs/assignment7/inputs/{sales.csv,empty.csv,headings.csv,unsupported.txt}` without modification. Sales: 10+20+30+40+50+60=210; 210/6=35; range 10–60; six rows, two columns, zero blanks.

`fixtures/two_sheets.xlsx` is generated by `make_fixture.py`, with headers Product and Sales, alternating Apple/Banana and no missing cells:

| Sheet | Sales data | Rows | Columns | Total | Mean | Min | Max |
|---|---|---|---|---|---|---|---|
| First | 4, 8, 12, 16 | 4 | 2 | 40 | 40/4=10 | 4 | 16 |
| Second | 5, 15, 25, 25, 35, 45 | 6 | 2 | 150 | 150/6=25 | 5 | 45 |

First precedes Second in workbook order. Both are usable. Test 05 verifies First initially, then switches to Second without another upload and checks the selector name and all listed statistics. Test code uses these literal arithmetic expectations independently of application modules.

Scope: six requested scenarios on one installed browser; this is not a cross-browser certification or a visual-content comparison of the exported chart.
